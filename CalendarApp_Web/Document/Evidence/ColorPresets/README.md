# 단계별 색상 프리셋 검증

2026-10-22 사용자 승인 범위. 격리 origin http://127.0.0.1:5175/에서 테스트 일정을 생성해 확인했다. 운영 origin·DB·기존 일정 원본은 접근하지 않았다.

책임은 UI 초안(ScheduleColorSettings) → 상태 Hook → 순수 정책·저장 어댑터로 나눈다. 일정 표시색은 파생 결과이며 프리셋 변경만으로 일정 원본을 다시 저장하지 않는다. 기존 colorMode 누락 일정은 수동으로 취급한다.
