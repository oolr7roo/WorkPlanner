# DATA-005 일정 체크리스트

[상위 데이터](../11_DataRequirements.md), [저장 계약](../12_api_spec/API-001_LocalStorage.md), [모듈 책임](../10_ModuleMapping.md). FR-015를 지원한다.

| 필드 | 형식 | 제약 |
| --- | --- | --- |
| checklist | 선택적 배열 | 부재는 빈 목록, 배열 순서가 표시 순서 |
| checklist[].id | 문자열 | 비어 있지 않은 문자열, 한 일정 안에서 고유; 신규 항목은 UUID |
| checklist[].text | 문자열 | 저장 시 trim, 빈 항목 거부 |
| checklist[].done | boolean | 완료 여부 |

신규 항목은 crypto.randomUUID로 id를 발급한다. 기존 일정에 checklist가 없으면 빈 목록으로 읽는다. 필드가 존재하지만 형식이 잘못되면 기존 일정 복원 오류 정책을 따른다. 완료 수는 목록에서 계산하며 저장 필드를 추가하지 않는다.

편집 초안은 원본 배열/항목을 복제하며 저장 시에만 일정에 반영한다. 취소·닫기·Escape는 초안을 버린다. 완료 토글과 삭제도 같은 경계를 따른다. 체크리스트 항목은 하위 일정이 아니며 시작/종료·계층·우선순위·단계별 색상을 변경하지 않는다. 부모 삭제 시 보존되는 자식의 체크리스트도 유지된다.

기존 localStorage 일정 v2 키 안에 함께 저장하고 서버·DB·별도 저장 키를 추가하지 않는다. 메모리 변경 뒤 쓰기 실패 시 오류를 표시하며 브라우저 보존은 보장하지 않는다. 다중 탭 동기화·공유·별도 마감일·체크리스트 재정렬은 이번 범위 밖이다.
