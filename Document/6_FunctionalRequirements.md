# 기능 요구사항

현재 기능 기준선이다. 2026-10-22 사용자 승인으로 단계별 색상 프리셋과 자동·직접 색상 선택을 추가했다. 전체 품질 승인 상태는 Review다.

## 기능 목록

### UF-001 달력 탐색

앱을 연다. 동일 일정 집합의 표시 범위를 전환한다.

```text
├─ FR-001 현재 기간 및 월·주·일 보기 탐색
│  └─ NFR-003 참조
```

### UF-002 일정 등록

새 일정을 시작한다. 유효한 입력을 새 일정으로 반영하고 편집 상태를 닫는다.

```text
├─ FR-002 새 일정 입력과 등록
│  └─ NFR-001 참조
├─ FR-008 제목·기간 오류 및 저장 실패 안내
│  └─ NFR-002 참조
```

### UF-003 일정 수정

기존 일정을 선택한다. 같은 일정의 내용을 갱신하고 편집 상태를 닫는다.

```text
├─ FR-003 기존 일정 내용 갱신
│  └─ NFR-001 참조
```

### UF-004 일정 삭제

기존 일정을 선택한다. 선택 일정만 제거하고 편집 상태를 닫는다.

```text
├─ FR-004 선택 일정 삭제
│  └─ NFR-001 참조
```

### UF-005 기간 직접 조정

일정을 다른 시간으로 이동하거나 길이를 바꾼다. 달력이 전달한 시작·종료값으로 해당 일정을 변경한다.

```text
├─ FR-005 일정 이동·길이 조정 결과 반영
│  └─ NFR-001 참조
```

### UF-006 편집 취소

편집 중 취소하거나 닫는다. 초안을 저장하지 않고 달력으로 돌아간다.

```text
├─ FR-006 편집 초안을 반영하지 않고 종료
│  └─ NFR-002 참조
```

### UF-007 기존 일정 다시 사용

같은 브라우저·origin에서 앱을 다시 연다. 저장된 기록 중 지원 형식인 일정들을 복원한다.

```text
├─ FR-007 같은 사용 환경의 일정 보존·복원
│  └─ NFR-001 참조
```

### UF-008 로컬 실행 관리

시작 명령을 실행한다. 웹 실행 환경과 관리 중인 저장 기반을 종료한다.

```text
├─ FR-009 설정 검증과 로컬 실행·종료 제어
│  └─ NFR-004 참조
├─ FR-010 로컬 데이터베이스 존재 확인·준비
│  └─ NFR-004 참조
├─ FR-011 데이터베이스 프로세스 시작·정지 관리
│  └─ NFR-004 참조
├─ FR-012 웹 제공과 DB 파일 접근 차단
│  └─ NFR-005 참조
```

### UF-009 단계별 색상 설정

설정을 열어 프리셋을 선택·추가하고 단계 색상을 미리 확인한 뒤 저장하거나 취소한다.

```text
├─ FR-013 단계별 색상 프리셋 편집·선택·보존
│  ├─ NFR-001 참조
│  └─ NFR-002 참조
```

### UF-002·UF-003 색상 선택 확장

새 일정은 단계별 자동 색상을 사용하고 기존 일정은 저장된 색상을 유지한다. 편집에서 자동과 직접 지정을 선택한다.

```text
├─ FR-014 일정 단계별 자동 색상 및 직접 지정 우선 적용
│  └─ NFR-001 참조
```

## 공통 비기능 요구사항

### NFR-001

- 적용 기능: FR-002, FR-003, FR-004, FR-005, FR-007, FR-013, FR-014
- 요구사항: 저장소가 허용된 동일 브라우저·origin에서 변경한 제목·시간·색상과 일정 식별자는 새로고침 뒤 동일해야 한다.
- 검증 기준: 정상 보존 사례의 변경 전후 기록 비교; 저장 실패는 보존 보장 제외

### NFR-002

- 적용 기능: FR-006, FR-008, FR-013
- 요구사항: 유효하지 않은 기간 저장과 편집 취소는 기존 일정 집합을 변경하지 않아야 하며, 저장 실패 시 오류 안내가 표시되어야 한다.
- 검증 기준: 입력 실패·취소 전후 일정 집합이 동일하고 저장 실패 안내가 관찰됨

### NFR-003

- 적용 기능: FR-001
- 요구사항: 한국어 월·주·일 선택과 기간 탐색 후 일정 데이터가 변하지 않아야 한다.
- 검증 기준: 보기 변경 전후 동일 일정 집합; 선택 보기 버튼의 눌림 상태 확인

### NFR-004

- 적용 기능: FR-009, FR-010, FR-011
- 요구사항: 준비 실패 시 웹 준비 완료로 표시하지 않아야 하며 정상 종료 후 감독 프로세스 상태가 stopped여야 한다.
- 검증 기준: 시작 오류 종료 코드와 상태 확인; 실제 DB 종료는 별도 프로세스 상태 검증

### NFR-005

- 적용 기능: FR-012
- 요구사항: 웹과 DB 리스너는 loopback에서 제공되고 웹 경로를 통한 PostgreSQL 디렉터리 요청은 404로 거부되어야 한다.
- 검증 기준: 리스너 설정 및 DB 경로 응답 확인

## 확인 필요 사항

성능 상한·지원 브라우저 공식 범위·키보드 접근성 적합성·가용성 SLA는 측정 또는 승인 근거가 없다. 현재 기준선에 수치를 만들어 넣지 않는다.
