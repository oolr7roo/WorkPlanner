# CalendarApp 사용자 흐름

## 1. 입력 근거

| 근거 ID | 요구사항 | 반영 흐름 |
| --- | --- | --- |
| CR-001 | 개인 일정을 기간별로 파악할 수 있어야 한다. | UF-001 |
| CR-002 | 일정을 등록하고 변경·삭제하여 자신의 계획을 유지할 수 있어야 한다. | UF-002, UF-003, UF-004, UF-005, UF-006 |
| CR-003 | 같은 사용 환경에서 기존 일정 기록을 다시 사용할 수 있어야 한다. | UF-007 |
| CR-005 | 로컬 실행 환경을 시작하고 종료할 수 있어야 한다. | UF-008 |

CR-004는 UF-002·003·007의 오류 상황에 적용한다. CR 후보의 고객 확인 상태는 입력 문서 그대로 유지한다.

## 3. 사용자 흐름 상세

### UF-001 달력 탐색

| 단계 | 사용자 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | 앱을 연다. | 현재 기간의 월 보기와 기존 일정을 표시한다. |
| 2 | 이전·다음·오늘을 선택한다. | 표시 기간을 변경한다. |
| 3 | 월·주·일 보기를 선택한다. | 동일 일정 집합의 표시 범위를 전환한다. |

### UF-002 일정 등록

| 단계 | 사용자 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | 새 일정을 시작한다. | 새 일정 편집 상태를 연다. |
| 2 | 제목·기간·색상을 입력한다. | 입력값을 편집 상태에 반영한다. |
| 3 | 저장한다. | 유효한 입력을 새 일정으로 반영하고 편집 상태를 닫는다. |

#### 예외 흐름

E-01: 제목 누락 또는 종료가 시작보다 늦지 않으면 오류를 알리고 현재 편집 상태에 머문다. 저장 실패는 달력에 안내하지만 편집 화면을 다시 열지 않는다.

#### 분기 흐름

B-01: 시간 구간을 선택해 시작하면 선택 기간을 초기값으로 사용한다. 종료값이 없는 시작은 한 시간 뒤를 초기 종료로 사용한다. 이후 본 흐름 2단계로 합류한다.

### UF-003 일정 수정

| 단계 | 사용자 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | 기존 일정을 선택한다. | 현재 내용으로 편집 상태를 연다. |
| 2 | 내용을 변경하고 저장한다. | 같은 일정의 내용을 갱신하고 편집 상태를 닫는다. |

#### 예외 흐름

E-01: 제목 누락 또는 종료가 시작보다 늦지 않으면 오류를 알리고 현재 편집 상태에 머문다. 저장 실패는 달력에 안내하지만 편집 화면을 다시 열지 않는다.

### UF-004 일정 삭제

| 단계 | 사용자 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | 기존 일정을 선택한다. | 편집 상태를 연다. |
| 2 | 삭제한다. | 선택 일정만 제거하고 편집 상태를 닫는다. |

### UF-005 기간 직접 조정

| 단계 | 사용자 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | 일정을 다른 시간으로 이동하거나 길이를 바꾼다. | 달력이 전달한 시작·종료값으로 해당 일정을 변경한다. |

### UF-006 편집 취소

| 단계 | 사용자 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | 편집 중 취소하거나 닫는다. | 초안을 저장하지 않고 달력으로 돌아간다. |

#### 분기 흐름

B-01: 배경 자체를 누른 경우에도 취소한다. 편집 영역 내부를 누르면 닫지 않는다. 이후 종료한다.

### UF-007 기존 일정 다시 사용

| 단계 | 사용자 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | 같은 브라우저·origin에서 앱을 다시 연다. | 저장된 기록 중 지원 형식인 일정들을 복원한다. |

#### 예외 흐름

E-01: 읽기 실패·손상 기록은 빈 목록으로 시작한다. 오류 복구 안내는 제공되지 않는다. 이후 UF-001로 이동한다.

### UF-008 로컬 실행 관리

| 단계 | 사용자 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | 시작 명령을 실행한다. | 저장 기반과 웹 실행 환경을 준비한다. |
| 2 | 준비된 앱을 연다. | 달력 사용이 가능해진다. |
| 3 | 종료 명령을 실행한다. | 웹 실행 환경과 관리 중인 저장 기반을 종료한다. |

#### 예외 흐름

E-01: 의존성·포트·저장 기반 준비 실패는 시작 실패로 끝나며 실행 로그를 남긴다. 반복 시작은 기존 앱을 다시 여는 경로와 직접 시작 실패 경로가 구분된다.

### UF-009 단계별 색상 설정

| 단계 | 사용자 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | 일정 추가 오른쪽 설정을 누른다. | 활성 프리셋 초안과 단계별 색상·미리보기를 연다. |
| 2 | 프리셋을 선택하거나 추가하고 이름·단계 색상을 수정한다. | 자동 색상 트리를 미리 보여주며 최소 두 가지 다른 색상을 검사한다. |
| 3 | 저장한다. | 같은 브라우저에 설정을 저장한 뒤 자동 일정 표시색에 반영한다. |

취소·닫기·Escape는 설정과 일정을 바꾸지 않는다. 저장 실패는 안내하고 초안을 유지한다. 손상 설정은 원본을 덮어쓰지 않고 기본 프리셋으로 표시하며 복구 안내를 제공한다.
