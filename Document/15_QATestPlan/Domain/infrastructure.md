# infrastructure QA 상세

## 1. 테스트 범위

infrastructure 현재 책임 경계와 오류·회귀 경로를 검증한다. 수행 결과를 이 계획 문서에 쓰지 않는다.

## 2. 테스트 환경

상위 QA 환경과 해당 플랫폼을 따른다. 사용자 데이터·실행 중 서비스는 보존하고 격리 프로필·복제 클러스터·별도 포트를 사용한다.

## 4. 테스트 케이스 상세

### TC-012

- 전제 조건: 설정 검사의 원본 구현·계약이 존재하고 격리 환경이 준비됨.
- 절차: 격리 설정 사본의 누락·중복·동일 포트·범위 이탈을 검사한다.
- 기대 결과: 유효 설정만 통과하며 기존 설정 파일은 보존한다.
- 대체 확인 방법: 관련 source·설정·콜백·명령 계약을 정적으로 대조하고 동적 검증 미실행을 명시한다. 대체 확인은 실행 통과와 다르다.

### TC-013

- 전제 조건: 감독자 제어의 원본 구현·계약이 존재하고 격리 환경이 준비됨.
- 절차: 격리 포트에서 start·status·wait·stop·중복 start를 확인한다.
- 기대 결과: 준비 순서·응답·종료 코드와 현재 계약이 일치한다.
- 대체 확인 방법: 관련 source·설정·콜백·명령 계약을 정적으로 대조하고 동적 검증 미실행을 명시한다. 대체 확인은 실행 통과와 다르다.

### TC-014

- 전제 조건: 플랫폼 DB 관리의 원본 구현·계약이 존재하고 격리 환경이 준비됨.
- 절차: Mac·Windows별 도구 경로와 별도 데이터 경로를 확인한다.
- 기대 결과: 외부 실행 DB 거부·loopback·실패 정지 동작이 재현된다.
- 대체 확인 방법: 관련 source·설정·콜백·명령 계약을 정적으로 대조하고 동적 검증 미실행을 명시한다. 대체 확인은 실행 통과와 다르다.

### TC-015

- 전제 조건: DB 경로 차단의 원본 구현·계약이 존재하고 격리 환경이 준비됨.
- 절차: postgresql segment·대소문자·인코딩·역슬래시 경로를 요청한다.
- 기대 결과: DB 경로 404, malformed encoding 400; 비밀 파일 본문 미조회.
- 대체 확인 방법: 관련 source·설정·콜백·명령 계약을 정적으로 대조하고 동적 검증 미실행을 명시한다. 대체 확인은 실행 통과와 다르다.

## 5. 회귀 테스트 기준

해당 책임의 source 또는 계약 변경 시 위 케이스를 다시 확인한다. 공유 계약 변경은 관련 다른 도메인의 QA와 통합 경로까지 확장한다.

## 6. 확인 필요 사항

권한·동시성·복구·플랫폼·시각 적합성 검증을 자동 통과로 처리하지 않는다.
