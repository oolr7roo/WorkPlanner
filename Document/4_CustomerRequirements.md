# CalendarApp 고객 요구사항

## 1. 문서 목적

현재 구현에서 역으로 정리한 고객 목표 후보다. 사용자가 승인한 것은 현재 구현 기준 문서 작성이며, 별도의 고객 인터뷰·목표·우선순위 승인은 없으므로 요구사항 확인 상태를 모두 확인 필요로 둔다.

## 2. 요구사항 범위

| 포함 / 제외 | 내용 | 이유 |
| --- | --- | --- |
| 포함 | 개인 일정 파악·관리·보존·실행 결과 | 구현에서 식별한 상위 목표 |
| 제외 | 조직 공유·알림·동기화·수익화 | 현 구현 밖 |

## 3. 요구사항 목록

| ID | 고객 목표 상태 | 분류 | 우선순위 | 근거 ID | 확인 상태 |
| --- | --- | --- | --- | --- | --- |
| CR-001 | 개인 일정을 기간별로 파악할 수 있어야 한다. | 정보 | Must | PP-001 | 확인 필요 |
| CR-002 | 일정을 등록하고 변경·삭제하여 자신의 계획을 유지할 수 있어야 한다. | 업무 | Must | PP-001 | 확인 필요 |
| CR-003 | 같은 사용 환경에서 기존 일정 기록을 다시 사용할 수 있어야 한다. | 정보 | Must | PP-002 | 확인 필요 |
| CR-004 | 시간 입력 문제와 저장 실패를 인지할 수 있어야 한다. | 업무 | Must | PP-005 | 확인 필요 |
| CR-005 | 로컬 실행 환경을 시작하고 종료할 수 있어야 한다. | 운영 | Must | PP-004 | 확인 필요 |

Must는 현 구현 범위 정리를 위한 작성자 분류이며 고객 합의가 아니다. 현재 범위를 설명하는 후속 문서 작성은 사용자의 일괄 작성 지시에 따라 진행한다.
