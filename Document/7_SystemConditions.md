# 시스템 조건

## 문서 목적

설계 전제와 구현·운영을 제한하는 현재 조건을 분리한다. 하드웨어 최소 사양이나 일정·인력·예산 제한은 확인 근거가 없어 확정하지 않는다.

## 시스템 전제

| ID | 전제 | 분류 | 검증 상태 |
| --- | --- | --- | --- |
| SA-001 | 일정 사용은 한 기기의 같은 브라우저 프로필에서 이루어진다. | 사용자 | 미검증 |
| SA-002 | 브라우저 저장소를 읽고 쓸 수 있다. | 환경 | 미검증 |
| SA-003 | 사용 기기의 현지 시간 설정이 사용 의도와 같다. | 환경 | 미검증 |
| SA-004 | Node.js와 선택 플랫폼의 PostgreSQL 실행 파일이 준비되어 있다. | 플랫폼 | 검증 중 |

## 시스템·하드웨어 제약

| ID | 제약 | 분류 | 근거 |
| --- | --- | --- | --- |
| CT-001 | 일정은 브라우저 origin별 저장 범위에 제한되고 서버와 동기화되지 않는다. | 기술 | 일정 보존 구현 |
| CT-002 | 웹과 DB는 서로 다른 1~65535의 포트 및 loopback에 제한된다. | 플랫폼 | 설정·실행 구현 |
| CT-003 | 실행 스크립트는 Windows 또는 macOS 환경을 대상으로 한다. | 플랫폼 | 시작·종료 스크립트 |
| CT-004 | macOS와 Windows의 DB 데이터 디렉터리는 독립되어 직접 이식되지 않는다. | 기술 | 플랫폼별 DB 관리 구현 |

## 확인 필요 사항

사용자 시간대 변경·브라우저 비공개 모드·기업 정책·디스크 용량의 실제 운영 범위와 Windows 현장 검증은 미확정이다. SA-004의 검증 중은 현재 호스트에서 Node 빌드가 통과했지만 전체 운영 환경을 확인하지 않았다는 뜻이다.
