# 시스템 조건

## 문서 목적

설계 전제와 구현·운영을 제한하는 현재 조건을 분리한다. 하드웨어 최소 사양이나 일정·인력·예산 제한은 확인 근거가 없어 확정하지 않는다.

## 시스템 전제

| ID | 전제 | 분류 | 검증 상태 |
| --- | --- | --- | --- |
| SA-001 | 같은 기기의 브라우저와 AI가 한 사람의 개인 일정 범위를 사용한다. | 사용자 | 미검증 |
| SA-002 | 기존 기록 가져오기·접힘 보존을 사용할 때 브라우저 저장소에 접근할 수 있다. | 환경 | 미검증 |
| SA-003 | 브라우저 현지 시각과 앱의 기준 시간대가 사용 의도에 맞게 설정되어 있다. | 환경 | 미검증 |
| SA-004 | Node.js와 선택 플랫폼의 PostgreSQL 실행 파일이 준비되어 있다. | 플랫폼 | 검증 중 |

## 시스템·하드웨어 제약

| ID | 제약 | 분류 | 근거 |
| --- | --- | --- | --- |
| CT-001 | 과거 브라우저 기록은 origin별로 분리되며 명시적으로 같은 로컬 개인 저장 범위에 이전한다. 원격 접근·다중 사용자 공유는 포함하지 않는다. | 기술 | 일정 보존 구현 |
| CT-002 | 웹과 DB는 서로 다른 1~65535의 포트 및 loopback에 제한된다. | 플랫폼 | 설정·실행 구현 |
| CT-003 | 실행 스크립트는 Windows 또는 macOS 환경을 대상으로 한다. | 플랫폼 | 시작·종료 스크립트 |
| CT-004 | macOS와 Windows의 DB 데이터 디렉터리는 독립되어 직접 이식되지 않는다. | 기술 | 플랫폼별 DB 관리 구현 |
| CT-005 | 공통 일정·AI 연결 실행 환경은 Node.js 22.18 이상을 사용한다. | 기술 | 승인된 로컬 AI 연결 구현 범위 |
| CT-006 | 일정 시각은 하나의 기준 시간대에서 초 단위로 표현하며 기본 기준은 Asia/Seoul이다. | 기술 | 승인된 공통 일정 저장 범위 |

## 확인 필요 사항

사용자 시간대 변경·브라우저 비공개 모드·기업 정책·디스크 용량의 실제 운영 범위와 전체 Windows 운영 환경 검증은 미확정이다. 현재 호스트에서 정상 실행·DB 장애·재연결을 확인했으나 다른 플랫폼 전체 적합성으로 확대하지 않는다. SA-004의 검증 중은 현재 호스트에서 Node 빌드가 통과했지만 전체 운영 환경을 확인하지 않았다는 뜻이다.
